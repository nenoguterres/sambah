- Card estilo WhatsApp com quatro caminhos.

## Quatro caminhos

- Pedir agora
- Levar o Food Truck
- Reservar no Xeriffe
- Falar no WhatsApp

## Direção visual

- Limpo.
- Escuro.
- Verde.
- Humano.
- Comercial.
- Sem poluição visual.
- Sem folhas demais.
- Primeira dobra com clareza.

## Aplicação na home pública

- `public/site.html` deve usar `logo-sambah-oficial.png`.
- `public/site.html` e `public/site.js` devem usar `capbah-oficial.png`.
- O placeholder deve ser removido quando `capbah-oficial.png` existir.
- O visual humanizado deve ser mantido.
- A primeira dobra deve continuar limpa.
- Os quatro caminhos devem permanecer visíveis.
