# SAMBAH-VOICE-SECURITY

## Regras de seguranca

- Audio nao executa acao critica diretamente.
- Transcricao e obrigatoria antes de intent.
- Intent critica exige confirmacao explicita.
- Pagamento passa pelo SamBah Pay.
- AutoServe passa por release_token.
- Release token expira e e de uso unico.
- Toda etapa e auditada.
- Falha de entendimento gera evento de auditoria.
- Handoff humano e registrado.
