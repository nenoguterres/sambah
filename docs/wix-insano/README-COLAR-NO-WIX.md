# Colar no Wix

1. Ative o Dev Mode / Velo no Wix.
2. Crie uma página chamada `Pedir`.
3. Adicione estes elementos na página com os IDs exatos:
   - `#produtoDropdown`
   - `#nomeInput`
   - `#telefoneInput`
   - `#quantidadeInput`
   - `#observacaoItemInput`
   - `#formaEntregaDropdown`
   - `#enderecoInput`
   - `#formaPagamentoDropdown`
   - `#observacoesInput`
   - `#enviarPedidoButton`
   - `#resultadoText`
   - `#abrirWhatsAppButton`
4. Cole o conteúdo de `wix-pedido-insano.js` no código da página.
5. Publique o site.
6. Faça um pedido de teste.
7. Confira o pedido no SamBah.
8. Configure `INSANO_WHATSAPP_NUMBER` no Render para liberar `whatsappUrl`.
