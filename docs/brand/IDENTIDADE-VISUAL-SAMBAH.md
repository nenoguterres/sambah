# Identidade Visual samBah!

## Nome oficial

samBah!

## Significado

O samBah! é o atendimento rápido do Insano com alma gaúcha: digital, humano, direto e comercial. Ele organiza pedidos, reservas e eventos sem parecer um sistema técnico para o cliente.

## Cores principais

- Grafite escuro como base da landing pública.
- Verde WhatsApp como cor principal de ação e destaque.
- Branco para leitura e presença da marca.
- Cinza claro para textos secundários.
- Vermelho apenas no lenço do CapBah.
- Marrom, cuia e madeira apenas como detalhe visual.

## Regras de uso

- Não usar azul na marca.
- Não usar excesso de folhas.
- Não usar visual de painel técnico na home pública.
- CapBah é anfitrião, não enfeite.
- A home deve parecer conversa, não sistema.
- A primeira dobra deve ser limpa, clara e focada nos quatro caminhos principais.
